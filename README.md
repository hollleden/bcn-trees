# BCN Trees — Интерактивная карта деревьев Барселоны

## Что это

Одностраничное веб-приложение на HTML+CSS+JS+Leaflet. Показывает 208 деревьев
из каталога мэрии Барселоны «Arbres d'interès local» на карте с фильтрами,
списком, детальными карточками. Двуязычное (RU/ES).

## Файлы

- `build.py`      — Python-скрипт, читает `trees_complete.json`, генерирует `index.html`
- `index.html`    — собранная страница (открывается двойным кликом)
- `trees_complete.json` — база 208 деревьев
- `trees_full.json`, `trees_enriched.json`, `trees.js`, `trees_cache.jsonl` — исходные данные

- `_stable/`  — снимок v26.8 (до правок). Точка отката.
- `_archive/` — все прошлые итерации build_v2.py … build_v44.py

## Как пересобрать

    cd ~/Downloads/bcn-trees
    python3 build.py
    open index.html

## Что реализовано

- Карта Leaflet с кластеризацией
- Фильтры: категория, район, собственность, возраст, крона, ствол, посещённые
- Поиск по всем полям (кириллица + латиница)
- Детальные карточки: фото-аккордеон, латынь, описание, характеристики, маршрут
- Мобильная шторка (bottom sheet): collapsed 72px / expanded 90vh,
  свайп вверх-вниз, velocity-триггер, центрирование карты под шторкой
- Eco-bento палитра
- Двуязычие RU / ES
